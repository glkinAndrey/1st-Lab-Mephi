# 1st-Lab-Mephi

**Почему 0.1 + 0.2 не даёт 0.3?**

В компьютере числа с плавающей точкой хранятся в двоичной системе. Десятичные дроби, которые в десятичной системе выглядят «красиво» (например, 0.1, 0.2), в двоичной системе становятся бесконечными периодическими дробями, точно как 1/3 в десятичной = 0.33333…


**SquareMatrix A = {0};**

это определение матрицы с нулевым размером (size = 0, data = NULL, typeInfo = NULL). Такая матрица не хранит элементов и не пригодна для арифметических операций (сложение, умножение). Она нужна только как начальное пустое состояние, чтобы потом её можно было проинициализировать.
